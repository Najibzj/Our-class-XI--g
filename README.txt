OUR CLASS XI-G — STARTER UI DIPERBARUI

Cara membuka:
1. Ekstrak ZIP.
2. Buka folder Our-Class-XI-G-Updated di VS Code.
3. Buka index.html lalu jalankan dengan Live Server, atau buka index.html langsung di browser.

Isi:
- Login pilihan Murid/Guru dan jabatan
- Dashboard
- Denah 15 meja (3 kolom x 5 baris) + meja guru
- Pengumuman, absensi, tugas, tagihan
- Profil anggota, playlist, sosial media/saluran
- Jadwal pelajaran dan jadwal pakaian
- Desain responsif HP dengan warna cokelat/navy

Akun demo:
- Anggota: riski / 12345
- Sekretaris: pilih Sekretaris, sandi PWSS
- Bendahara: pilih Bendahara, sandi KASX
- Ketua: pilih Ketua, sandi KETUAX
- Guru: pilih Guru, sandi SSSG

PENTING:
Ini masih prototipe frontend. Data hanya tersimpan sementara di memori browser dan tidak dibagikan ke semua pengguna. Login dan sandi demo hanya untuk uji tampilan, bukan keamanan sungguhan. Untuk website online 24 jam dengan database bersama, langkah berikutnya adalah menghubungkan Google Sheets + Google Apps Script dan hosting.
